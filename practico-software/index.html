0 · Cómo funciona este bloque

Ya has estudiado la teoría del software (Bloque 02) y has hecho el cuestionario sobre el software. Aquí no se repite la teoría: solo se recuerdan brevemente las ideas necesarias para trabajar.

  • Software = el conjunto de programas e instrucciones que permiten que un ordenador realice tareas.
  • Hardware = la parte física y tangible del sistema informático.
  • Software de sistema = programa principal que gestiona el equipo: el sistema operativo, los controladores o drivers y las utilidades básicas.
  • Software de aplicación = programas con los que realizas tareas concretas: ofimática (Word, Excel, Access, PowerPoint, Outlook) y aplicaciones sanitarias (historia clínica electrónica, gestión de citas…).

💡 Idea clave: aquí no se memoriza teoría nueva: se practica hasta distinguir el software del hardware, reconocer el sistema operativo y saber personalizar un puesto.

Objetivos del bloque

  • Distinguir software y hardware y clasificar los programas por su tipo.
  • Reconocer el sistema operativo y las funciones de los controladores (drivers).
  • Relacionar cada aplicación con su función y su tarea sanitaria.
  • Personalizar y configurar los aspectos básicos de un puesto.
  • Elaborar un inventario sencillo de software de un puesto.

Trabajarás las mismas situaciones de un servicio de Documentación y Administración Sanitarias: admisión, consultas, archivo y laboratorio.

Las actividades se autocorrigen en esta página y puedes repetirlas las veces que quieras.

1 · Identificación de software y hardware

Recordatorio breve: todo lo que se puede ver y tocar es hardware; todo lo que son programas e instrucciones es software. El software se divide en software de sistema (sistema operativo, drivers) y software de aplicación (ofimática, aplicaciones sanitarias).

1.1 · Baraja de reconocimiento

Todas las tarjetas muestran el nombre de un programa de software: sistema operativo, controladores (drivers), ofimática y aplicaciones sanitarias. Haz clic sobre cada tarjeta para voltearla y ver su tipo y función.

1.2 · Relaciona cada programa con su función

Une cada programa con la función que realiza. Selecciona un elemento de la izquierda y pulsa su pareja de la derecha.

💡 Idea clave: saber solo el nombre de un programa no basta: lo importante es para qué sirve en tu trabajo.

2 · El sistema operativo y sus funciones

Recordatorio breve: el sistema operativo (Windows, Linux, macOS…) es el programa que gestiona el equipo: arranca el ordenador, administra los recursos y permite ejecutar las aplicaciones. Los controladores o drivers hacen de puente entre el sistema y cada dispositivo (impresora, escáner, tarjeta gráfica…).

2.1 · Resuelve qué software interviene

Te planteamos situaciones reales de un puesto sanitario. Decide qué elemento de software es el responsable en cada una y comprueba tu respuesta.

2.2 · Une cada aplicación con su tarea sanitaria

3 · Personalización y configuración del sistema

Recordatorio breve: antes de ponerse a trabajar conviene dejar el puesto a tu medida y ordenado: fecha y hora, resolución de pantalla, fondo de escritorio, accesos directos y una carpeta de trabajo para la documentación.

3.1 · Checklist de configuración

Marca uno a uno los pasos de la personalización del puesto. Cuando completes todos, el sistema queda listo y personalizado. Si dudas sobre cómo realizar alguna comprobación, pulsa «¿Cómo lo compruebo?» en el paso correspondiente.

Si algo no responde durante la configuración (aplicación que no abre, resolución incorrecta…), no se fuerza: se registra la incidencia y se avisa al servicio de mantenimiento. En nuestro aula harás lo mismo: anota la incidencia en la hoja que te proporcionará la profesora. Según el protocolo del centro, será la profesora quien tramite y registre la incidencia.

3.2 · Ordena los pasos

Coloca los pasos de la personalización y configuración de un sistema en el orden correcto. Pulsa las fichas en orden: 1 → 2 → 3…

Cuando completes el checklist entero y ordenes correctamente los pasos, se desbloquearán las soluciones en PDF de la configuración del sistema.

3.3 · Inventario de software

Un inventario de software es la relación de los programas presentes en un puesto. Marca los grupos de software que has encontrado en el equipo y genera el inventario: podrás descargarlo en PDF. Este movimiento forma parte del mantenimiento básico del puesto.

Personalizar + configurar + inventariar el software = un puesto ordenado y mantenimiento básico responsable de cualquier servicio sanitario.
